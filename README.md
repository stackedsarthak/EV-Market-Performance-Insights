# Electric Vehicle Market Performance & Insights

## Project Overview
This project explores electric vehicle (EV) data using Tableau to understand vehicle range, battery types, manufacturers, and available sales information.

## Objectives
- Explore EV manufacturers and vehicle counts.
- Compare vehicle range across battery types.
- Analyze sales information where available.
- Present insights through an interactive Tableau dashboard.

## Tools Used
- Tableau Public / Tableau Desktop
- CSV dataset
- GitHub

## Visualizations
1. Annual EV Sales by Manufacturer
2. EV Range by Battery Type
3. EV Count by Manufacturer

## Dashboard
The Tableau dashboard combines the visualizations and includes a manufacturer filter for interactive exploration.

## Dataset
The project uses a CSV dataset containing electric vehicle information. Refer to the original dataset source and its license before redistributing the data.

## How to View
Download the Tableau workbook from this repository and open it in Tableau. If the workbook uses an external CSV file, connect it to the correct dataset location.

## Limitations
Vehicle counts do not necessarily represent sales. Conclusions about sales should only be made when the dataset contains valid sales data.
